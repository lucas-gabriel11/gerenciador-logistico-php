# Gerenciador Logístico em PHP

Projeto prático desenvolvido para a disciplina de Fundamentos de Programação para Internet.

## Sobre o Projeto
Aplicação web desenvolvida em PHP para gerenciamento logístico. O sistema permite o cadastro e edição de produtos, endereços (origem e destino) e transportadores, além da geração de fretes e emissão de relatórios diários.

## Estrutura de Arquivos
* index.php — Página inicial e menu de navegação.
* conexao.php — Configuração de conexão com o banco de dados.
* produtos.php — Cadastro e edição de produtos.
* enderecos.php — Cadastro e edição de endereços.
* transportadores.php — Cadastro e edição de transportadores.
* fretes.php — Criação e gerenciamento de fretes.
* relatorios.php — Consulta e download de relatórios de fretes por dia.

## Tecnologias Utilizadas
* Backend: PHP
* rontend:HTML5, CSS3 e JavaScript
* Estilização: Bootstrap
* Banco de Dados: MySQL
* Servidor Local: XAMPP

## Como executar o projeto
1. Clone este repositório ou baixe os arquivos.
2. Coloque a pasta (gerenciador-logistico) dentro do diretorio (htdocs) do XAMPP.
3. Inicie os serviços Apache e MySQLno painel do XAMPP.
4. Acesse no navegador: `http://localhost/gerenciador-logistico`
